## 技术挑战与解决方案

### 挑战1: 分类输出形状不匹配（实验8）

**问题**: `clas`张量形状为`(batch_size, 1, 2)`而非预期的`(batch_size, 2)`

**解决方案**:
```python
# 修改前
probs = torch.softmax(clas, dim=1)
preds = torch.argmax(probs, dim=1)

# 修改后
probs = torch.softmax(clas, dim=-1)
preds = torch.argmax(probs, dim=-1).squeeze()
```

### 挑战2: 脉冲形状参数无法动态修改（实验9）

**问题**: SAEFit使用预录制真实波形，形状参数嵌入在二进制文件中

**解决方案**: 
- 实现参数化脉冲生成器（双指数衰减模型，217行代码）
- 系统测试16个形状条件：上升/下降时间±10%, ±20%, ±30%
- 生成3,584,000个测试样本完成完整评估
