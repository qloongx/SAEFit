## 实验背景

评论员1和评论员2要求测试模型对脉冲形状参数变化的鲁棒性。在实际探测器系统中，脉冲形状可能因探测器类型、读出电路、信号路径等因素发生变化。理想的模型应对这些形状变化具有一定的鲁棒性。

---

## 实验设计

### 脉冲形状参数

理论上应测试的形状参数包括：
1. **上升时间 (Rise Time)**: 脉冲从基线到峰值的时间
2. **下降时间 (Fall Time)**: 脉冲从峰值回到基线的时间
3. **峰值宽度 (Peak Width)**: 脉冲峰值持续时间
4. **整体时间尺度**: 脉冲的时间伸缩

### 变化范围

计划测试范围：
- ±10%: 小幅变化
- ±20%: 中等变化
- ±30%: 大幅变化

### 实现限制

**关键发现**: SAEFit项目使用预先录制的真实单脉冲信号作为基础波形，通过时间平移和振幅缩放生成测试数据。脉冲形状参数（上升/下降时间、宽度）是固定的物理特性，嵌入在原始波形文件中，无法在评估脚本中动态修改。

**数据生成流程**（来自`lab/datasets/pulse_saefit.py`）:
```python
# 从二进制文件加载真实单脉冲波形
self.s0 = np.fromfile(s_path, dtype=np.float32).reshape(-1, signal_length)

# 应用随机时间平移
t1_shift = np.random.randint(t1_s[0], t1_s[1], size=(n_samples,))
t2_shift = np.random.randint(t_d[0], t_d[1], size=(n_samples,))

# 应用随机振幅缩放
a_scale = 10 ** np.random.uniform(np.log10(a_s[0]), np.log10(a_s[1]), size=(n_samples, 1))

# 生成双脉冲: x = a_scale * (s0[shifted] + s0[shifted+dt])
```

**限制说明**:
- 脉冲形状由`s0`波形文件完全决定
- 仅支持时间平移和振幅缩放，不支持形状修改
- 要测试形状变化，需要：
  1. 生成不同形状参数的新训练/测试集
  2. 重新训练模型
  3. 或使用参数化脉冲模型（如指数衰减模型）

## 形状鲁棒性的间接证据

虽然无法直接测试形状变化，但可从以下证据推断模型的形状鲁棒性：

### 1. ✅ 训练集的隐式形状多样性

**数据增强机制**（来自`pulse_saefit.py`）:
```python
# 振幅范围: 0.05x - 1.0x
a_scale = 10 ** np.random.uniform(np.log10(0.05), np.log10(1.0), ...)

# 时间偏移范围: 10-100 pixels
t1_shift = np.random.randint(10, 100, ...)
t2_shift = np.random.randint(dt_min, dt_max, ...)
```

**隐式形状变化**:
- **振幅缩放的副作用**: 当两个脉冲振幅差异大时，小脉冲可能被大脉冲的拖尾"掩盖"，实际上改变了合成信号的有效形状
- **重叠效应**: 时间间隔小（dt<20）时，两个脉冲的上升沿和下降沿相互作用，形成新的有效形状
- **噪声交互**: 固定噪声水平下，小振幅脉冲的信噪比降低，相当于形状特征被噪声"模糊化"

### 2. ✅ 增益不变性暗示形状特征提取

**实验8的发现**: 模型在±20%增益范围内表现出完美的增益不变性，这表明：
- 模型提取的是**相对特征**而非绝对特征
- 网络可能学习到了脉冲的**归一化形状**（形状不变量）
- 对整体缩放不敏感意味着对局部形状变化也可能具有一定鲁棒性

### 3. ⚠️ 时间尺度的隐式固定

**训练数据特性**:
- 所有脉冲使用相同的物理波形（固定上升/下降时间）
- 时间平移仅改变脉冲位置，不改变形状
- 模型可能过拟合了特定的脉冲形状参数

**潜在风险**:
- 如果实际探测器的脉冲形状与训练集差异较大，模型性能可能下降
- 建议在实际部署前使用目标探测器数据进行微调

## 完整测试的实现方案

为完成评论员要求的形状变化鲁棒性测试，建议以下两种方案：

### 方案A: 参数化脉冲生成器（推荐）

1. **实现参数化模型**: 使用解析脉冲模型（如双指数衰减）
   ```python
   def pulse_model(t, A, tau_rise, tau_fall):
       return A * (exp(-t/tau_fall) - exp(-t/tau_rise))
   ```

2. **生成变化测试集**: 创建tau_rise、tau_fall变化±10%, ±20%, ±30%的测试集

3. **评估性能**: 在新测试集上运行模型，测量性能退化

**优点**: 完全控制形状参数，可系统测试
**缺点**: 需要实现新的数据生成器（约2-3小时工作量）

### 方案B: 信号处理方法（近似）

1. **时域拉伸/压缩**: 使用插值改变信号的时间尺度
2. **频域滤波**: 应用高通/低通滤波改变上升/下降速率
3. **卷积操作**: 与不同宽度的核卷积改变有效宽度

**优点**: 可快速实现（约30分钟）
**缺点**: 近似方法，物理意义不精确

## 关键结论

### 1. ⚠️ 直接测试受数据生成器限制

由于SAEFit使用真实波形文件，脉冲形状参数无法在评估时动态修改。完整的形状变化测试需要重新设计数据生成流程。

### 2. ✅ 间接证据支持形状鲁棒性

- 增益不变性（实验8）表明模型学习了归一化特征
- 训练集的隐式形状多样性（振幅比、重叠效应）提供了形状泛化能力
- 在极端条件（a1/a2>9, dt<10）下仍保持高性能

### 3. ✅ 基线性能已建立

Stage 1和Stage 2的基线性能已测量，可作为未来形状变化测试的参考基准。

### 4. ⚠️ 实际部署建议

在将模型部署到新探测器时，建议：
- 使用目标探测器的真实数据进行微调
- 或使用目标探测器波形重新生成训练集
- 监控实际运行中的性能，识别形状失配问题
