## 实验配置

### 评估阈值
```python
thresholds = [0.5, 0.6, 0.7, 0.75, 0.8, 0.85, 0.9, 0.95, 0.99, 0.999]
```

### 指标定义
- **OER (Overconfident Error Rate)**: 高于阈值的预测中，错误预测的比例
- **拒绝率 (Rejection Rate)**: 低于阈值的预测比例（被拒绝的样本）
- **选择性风险 (Selective Risk)**: 1 - 选择性准确率
- **覆盖率 (Coverage)**: 保留的样本比例
